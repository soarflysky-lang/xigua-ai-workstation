# 西瓜AI知识库

这是客户使用工作台时所需的核心知识资产，重点用于：
- 爆款选题
- 标题模板
- 抖音算法基础
- 冲量方向
- 商家/转行者内容路线

## 目录说明

- `douyin_algorithm.md`：抖音推荐机制与短视频结构
- `viral_title_templates.json`：爆款标题模板
- `hot_topics.md`：热门选题方向与模板
- `business_scripts.md`：商家增长型脚本模板

## 使用方式

1. 先看标题模板
2. 再看算法基础
3. 结合行业输入主题
4. 用脚本输出模板做视频
5. 反复迭代内容方向

## 面向对象

- 商家老板
- 转行者
- 需要做短视频赚钱的人
- 做 AI 自媒体内容工具的客户
