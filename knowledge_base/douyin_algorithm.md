# 抖音算法基础

## 1. 抖音为什么会推荐某条视频

抖音推荐机制核心看三个维度：

- 停留时长：用户看多久
- 互动率：点赞、评论、转发、收藏
- 内容相关性：视频和用户兴趣是否匹配

对于新账号，最重要的是前 3 秒抓住注意力，并让用户愿意继续看。

## 2. 适合新手的短视频结构

推荐结构：

1. 开头钩子（3秒）：明确痛点、冲突、悬念
2. 解决问题：讲清楚当前问题和真实场景
3. 给出方法：3个步骤最容易理解
4. 结尾呼吁：让用户做动作、评论、收藏

## 3. 适合做爆款的方向

- 赚钱思路
- 结构化经验总结
- 真实案例拆解
- 小白学习路径
- 商家转型路线

## 4. 具体建议

- 把“复杂知识”翻译成“简单步骤”
- 视频长度控制在 30~60 秒最合适，适合抖音快速消费
- 选题尽量围绕“痛点 + 结果 + 过程”展开
- 一条视频只解决一个问题，避免信息过载
