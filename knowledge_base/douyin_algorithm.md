# 抖音算法基础

## 1. 抖音为什么推荐某条视频

抖音推荐系统的关键指标通常包括：
- 停留时长
- 点赞、评论、转发、收藏
- 内容相关性
- 用户互动反馈

对于新账号而言，前 3 秒和内容结构更重要。任何一条视频最关键的不是“逻辑多完整”，而是“是否能让用户停下来继续看”。

## 2. 一条爆款视频最常见的结构

建议使用：
1. 开头钩子（前 3 秒）
2. 讲清问题
3. 给出方法
4. 结尾动作呼吁

例如：
- 问题：为什么很多人做了却没人看？
- 痛点：最容易踩的坑是什么？
- 方法：3 个步骤快速解决
- 结尾：评论区或收藏

## 3. 新手容易犯的错误

- 选题太大太泛
- 开头太长，拖住用户
- 讲概念多、方法少
- 没有明确变现/行动指引

## 4. 做爆款，优先考虑的方向

- 行业干货拆解
- 真实案例复盘
- 赚钱思路与方法谈论
- 小白操作路径
- 商家实操经验

## 5. 西瓜AI 的适用方式

用户只需要输入：
- 主题
- 行业
- 目标用户
- 视频风格

系统即可输出适合抖音传播的脚本框架。
